# OrgHub HRMS: Quick Start Cheat Cards

Printable, 1-page reference cards for the Phase 3 pilot.

---

## 📇 Card 1: Employee Punch & Leave Quick-Card

```
+-----------------------------------------------------------------------+
|                       ORGHUB HRMS - EMPLOYEE CARD                     |
+-----------------------------------------------------------------------+
| 📱 HOW TO CLOCK IN / OUT                                              |
| 1. Open OrgHub App on your mobile device.                             |
| 2. Check green GPS indicator: "Inside Office Geofence".               |
| 3. Tap [CLOCK IN] in the morning.                                     |
| 4. Tap [CLOCK OUT] before leaving office premises.                    |
|                                                                       |
| 🏖️ HOW TO APPLY FOR LEAVE                                             |
| 1. Web or Mobile: Go to "Leave & Time Off".                           |
| 2. Tap [Apply for Leave] -> Select Leave Type (Earned / Sick / Casual)|
| 3. Select Dates -> Verify live preview (shows balance after leave).   |
| 4. Add brief reason -> Tap [Submit].                                  |
|                                                                       |
| 🆘 NEED HELP?                                                         |
| - Navigate to "Helpdesk" in sidebar -> [New Ticket]                   |
| - Emergency IT/HR Support: Slack #pilot-support-internal              |
+-----------------------------------------------------------------------+
```

## 📇 Card 2: Manager Approvals & Roster Quick-Card

```
+-----------------------------------------------------------------------+
|                       ORGHUB HRMS - MANAGER CARD                      |
+-----------------------------------------------------------------------+
| 📥 HOW TO REVIEW LEAVE REQUESTS                                       |
| 1. Click Bell icon or go to "Approvals Inbox".                        |
| 2. Click on pending request:                                          |
|    - Review dates, reason, and team clash indicators.                 |
| 3. Click [Approve] or [Reject] (add comment if rejecting).            |
|                                                                       |
| ⏰ ATTENDANCE REGULARIZATION                                           |
| 1. Go to "Exceptions Inbox".                                          |
| 2. Check missed punch regularizations submitted by your team.         |
| 3. Verify justification and click [Approve]. Day auto-recalculates.   |
|                                                                       |
| 📅 TEAM CALENDAR                                                      |
| - Go to "Leave" -> "Team Calendar" for who is off today and upcoming. |
+-----------------------------------------------------------------------+
```

## 📇 Card 3: HR Operations & Migration Admin Card

```
+-----------------------------------------------------------------------+
|                     ORGHUB HRMS - HR ADMIN CARD                       |
+-----------------------------------------------------------------------+
| 📊 GENERATE REPORTS                                                   |
| 1. Navigate to "Reports & Analytics".                                 |
| 2. Select report (Muster Roll / Daily Summary / Leave Balances).      |
| 3. Filter by Date / Dept -> [Preview Top 50] -> [Export CSV / XLSX].  |
|                                                                       |
| 🚀 DATA MIGRATION ENGINE                                              |
| 1. Navigate to "Data Migration".                                      |
| 2. Download template CSV -> fill data -> Upload file.                 |
| 3. Check Preview Analysis -> [Confirm & Import].                      |
| 4. Need to revert? Click [Revert Batch] anytime.                      |
|                                                                       |
| 📈 PILOT TELEMETRY & CSAT                                             |
| - Check "Pilot Telemetry" for live adoption % and user CSAT scores.   |
+-----------------------------------------------------------------------+
```
